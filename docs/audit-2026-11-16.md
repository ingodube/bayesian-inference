# Functional and numerical stress audit

## Scope and reproducibility

`Rscript --vanilla research-pipeline/audit.R` validates each scenario before recording its pass/fail status in `artifacts/stress-audit.json`. It generates native fixtures for `node scripts/verify-parity.mjs ../artifacts/stress-fixtures.json` (run from `web/`). The Pages workflow runs both gates on every change.

The matrix contains 200 scenarios: all eight likelihoods, all three Normal inference modes, four prior settings and five sample sizes (20, 100, 500, 1,000, 2,500). It includes ordinary, weak, deliberately conflicting and reference priors. Generators use p=0.05, rate=2, Gamma shape=3, Normal mean=5/variance=30 and Rayleigh scale=2. Conflict examples are Beta(9900,100), Gamma(shape=10000,rate=10), Normal(-100,0.0001), IG(1000,999000), and a joint NIG with mean=-100 and kappa=10000. Credible levels are 99% at n=20 and 95% otherwise.

Each scenario checks equal-tailed probability mass, finite ordered density coordinates, nonnegative densities, interval shading and seeded data identity. Proper univariate cases also check the posterior/prior/likelihood identity independently in log space. Native unit checks separately cover boundary observations, improper posterior rejection, normalization, Rayleigh transformations and fixed sample prefixes. These are computational examples, not a repeated-sampling coverage experiment.

## Findings and corrections

1. **Valid heavy-tailed priors could suppress valid posteriors.** IG(0.001,0.001) has extreme upper quantiles beyond double precision. Prior summaries now tolerate unrepresentable quantiles, export an explicit numerical-limit status and display an explanation. Posterior interval validity is still mandatory. Density grids filter nonfinite quantiles before constructing sequences.
2. **Curve support did not cover the other distribution's viewport.** Each proper density now receives evaluation points across the displayed domain and near both peaks. This avoids truncated prior/posterior tails under strong conflicts.
3. **A true generating value could silently disappear.** The focused view now explains when truth is outside its range. The expanded view includes truth even for improper reference priors. Truth remains a separate marker when coincident with posterior summaries.
4. **Extreme numbers produced enormous table cells.** Very large/small finite values use scientific notation. Unrepresentable prior interval endpoints say “Beyond numeric range”, distinct from undefined moments.
5. **The joint Normal reference panel displayed the proper NIG update formula.** It now shows the actual reference marginal formulas, including the (n-1)/2 inverse-Gamma shape.
6. **Discrete plotting could allocate the entire theoretical support before limiting it.** The support bound is checked before allocating the integer sequence.
7. **Wrapped mobile legends overlapped the parameter-axis title.** Python now places posterior legends above the plot and provides additional chart height. At 390 px the legend and title occupy separate vertical regions.

## Validation evidence

- 200/200 stress scenarios passed native R validation.
- 200/200 stress scenarios passed native R/webR parity: 2,447,799 numerical comparisons, absolute tolerance 1e-8 plus relative tolerance 1e-6.
- The original 21-case parity suite passed: 264,049 numerical comparisons.
- 87 native statistical checks, two Python artifact checks, five Node tests and the TypeScript/production build passed.
- All stress-result panels were bound into Python-authored figures in both focused and expanded modes; tests verified finite axes, aligned finite traces, exact shaded interval endpoints and inclusion of truth in expanded views.
- Browser checks exercised a strongly conflicting Normal mean prior, the IG(0.001,0.001) prior, Bernoulli with 20 observed failures and both conflicting Beta/Jeffreys priors, Poisson with n=2,500 and a Gamma prior centered at 1,000, and Rayleigh transformed to sigma with n=2,500. Sample summaries stayed fixed when changing priors. Focused/expanded views and the numerical-limit explanation rendered successfully.
- A 390 px browser viewport (375 px content area) showed no horizontal page overflow for Rayleigh. After the legend fix, its legend ended at y=600.3 while the x-axis title began at y=839.9 in the inspected viewport; they no longer overlap. Desktop checks used 1,440 px.

Plot-grid comparisons collapse adjacent numerically coincident (x,y) vertices within relative 1e-12 before comparing coordinates. Native R and WASM can otherwise have different numbers of duplicate quantile vertices near the median. Statistical summaries, endpoints and observations are compared directly; this normalization does not relax their tolerances. Array lengths are checked explicitly, and failures save their request and both results for diagnosis.

Physical Android/iOS validation remains pending as described in `validation.md`. Viewport tests do not establish real-device performance or memory behavior.

## Future maintenance

Keep the numerical-limit distinction and viewport coverage rules in the statistical contract when adding new models. A repository-local skill for the sequence “native R stress matrix → Python artifact validation → webR parity → browser conflict tests → Pages verification” would make this audit repeatable for future contributors.
